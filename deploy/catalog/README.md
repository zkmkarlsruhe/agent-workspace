# Generic catalog

Skills use `workspace/*` frontmatter metadata. The MCP entries demonstrate
builtin and central gateways; they require matching integration selection,
service endpoints and operator configuration. Knowledge server names are
examples. The media image reference is illustrative; replace it with your
own reviewed image and digest before enabling the toolbox.

The minimal installation mounts an empty catalog. To enable entries, deploy
this directory at the instance catalog mount and configure the manager's
catalog directory. Source files alone do not activate tools.

See [MCP registration](https://zkmkarlsruhe.github.io/agent-workspace-docs/mcp-server/) and
[instance configuration](https://zkmkarlsruhe.github.io/agent-workspace-docs/instance/).
