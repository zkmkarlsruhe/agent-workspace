# Security

This is an evaluation-only prototype. Run it only on an internal network.
There is no security maintenance commitment, support period or response guarantee.

Use the repository's **Security > Report a vulnerability** form if private reporting
is enabled. Otherwise contact your deployment operator through an existing private
channel. Do not publish vulnerabilities, credentials or personal data in issues.
Private reporting availability must be checked before a public release.

Include the revision, affected component, sanitized configuration, reproduction
steps using synthetic data and observed impact. Never attach live credentials,
other people's files, transcripts or an unredacted database.

See [architecture](https://github.com/zkmkarlsruhe/agent-workspace-docs/blob/main/architecture.md) and [privacy](https://github.com/zkmkarlsruhe/agent-workspace-docs/blob/main/privacy.md) for boundaries
and retention limits. Reporting does not guarantee a response or fix.
