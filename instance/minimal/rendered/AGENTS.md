# Agent Workspace

Work inside the current project under /workspace/.

- results/: deliverables. New results use a free name; requested edits update the existing file.
- work/: scratch work.
- .project/brief.md: read the project brief.
- /workspace/.trash/: managed by the portal; do not read or change it.

Answer in the person's language. Check results and name sources.
