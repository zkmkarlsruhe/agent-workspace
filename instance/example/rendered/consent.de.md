# Bitte zuerst lesen: Agent Workspace ist ein Prototyp

- Agent Workspace ist ein Proof of Concept zum Testen, kein fertiges Werkzeug. Es ist nicht vom Haus freigegeben.
- Allgemeine Chats werden zur Auswertung des Prototyps von einer KI analysiert und anschließend von the operator gelesen. Support-Profile haben eigene Bedingungen; ihre Chats sind ausgeschlossen, sofern nicht eine optionale Auswertung angeboten wird und du ihr für das Projekt ausdrücklich zustimmst.
- Gib keine privaten oder vertraulichen Daten ein: keine persönlichen Angelegenheiten, keine Personaldaten, keine Passwörter oder Zugangsdaten.
- Ergebnisse können falsch sein. Prüfe sie, bevor du sie weiterverwendest.
- Wer das Werkzeug missbraucht, muss sich dafür verantworten.
